---
name: Mobile button brand colors
description: User direction for yellow button colors across the OG Landmark mobile app.
---

Mobile app ke Sign In aur baqi yellow/gold buttons official logo wala golden shade use karein; zyada bright yellow/orange shade use na karein.

**Why:** User ne Profile Sign In aur baqi yellow buttons ko official logo gold se match karne ko kaha.

**How to apply:** Button fills aur selected button states ke liye `splashGold` token use karein. Unrelated badges aur decorative text accents ko tabhi badlein jab user kahe.
