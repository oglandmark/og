---
name: Mobile button brand colors
description: User direction for yellow button colors across the OG Landmark mobile app.
---

Log In, Create Account aur unke email-verification primary buttons dark blue hone chahiye; baqi yellow/gold buttons official logo wala golden shade use karein, bright yellow/orange nahi.

**Why:** The user asked for the login and account-creation primary actions to match the app's dark-blue buttons while keeping the existing gold-button convention elsewhere.

**How to apply:** Login, signup, and signup verification primary actions use the navy style. Keep the official logo gold for unrelated gold buttons and selected states.
