---
name: Plot calculator geometry
description: Product rule for communicating reliable area calculations for irregular land plots.
---

Side lengths alone must never be presented as an exact area for an irregular polygon. Accurate mode uses diagonals from corner A to triangulate the plot; basic mode is limited to triangles and a clearly labelled rectangle-like four-side estimate.

**Why:** An irregular polygon can have multiple shapes with the same boundary lengths, so claiming exact area without enough measurements would mislead property users.

**How to apply:** Keep new calculator surfaces on the shared measurement model and preserve the explicit estimate/accurate wording when adding units, export formats, or web equivalents. If three entered sides violate the triangle inequality, do not block the user; return a clearly labelled approximate planning estimate.
