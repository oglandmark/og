OG LANDMARK — REBUILD LAND & PLOT MEASUREMENT CALCULATOR

Replace the current Land/Area Calculator with a professional, practical Land & Plot Measurement Calculator designed specifically for real-estate users in Pakistan.

IMPORTANT:
This is NOT a basic mathematical area calculator.
It should work like a real property/plot measurement tool used by property dealers, landowners, surveyors and buyers.

Do NOT use terms like “height”, “depth”, “base”, or other confusing geometry terminology in the user interface.

The user should simply enter the measurements of each side/boundary of the plot, just like a real plot is measured.

3. IMPORTANT AREA CALCULATION LOGIC
━━━━━━━━━━━━━━━━━━━━━━

Do NOT simply multiply two sides for every plot.

For regular 4-sided rectangular plots, calculate the area accurately.

For irregular 4-sided, 5-sided, 6-sided, 7-sided and 8-sided plots, provide a proper practical calculation method.

The best implementation is:

A) Allow the user to enter boundary side measurements.

B) Provide an optional “Add Diagonal Measurements” mode for irregular plots.

For irregular plots, side lengths alone do NOT uniquely determine the exact area. Therefore, the app must NOT falsely claim an exact area from insufficient information.

Instead:

“Basic Measurement”
→ calculate where mathematically possible.

“Accurate Irregular Plot Measurement”
→ allow the user to add diagonal measurements / additional measurements required to establish the plot geometry.

The app should guide the user clearly instead of producing a misleading result.

━━━━━━━━━━━━━━━━━━━━━━

This feature must be mathematically reliable.

For polygons where side lengths alone cannot uniquely determine the area:

• Clearly inform the user
• Request the required diagonal/additional measurements
• Use an appropriate polygon-area calculation method once sufficient geometry is available
• Clearly distinguish “Estimated Area” from “Calculated Area” where applicable

The app must never present an approximate result as an exact surveyed/legal land area.
